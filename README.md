# M5StickC Plus SE メカナムホイール 4輪ロボット ファームウェア

M5StickC Plus SE、PCA9685 (PWMドライバー)、L298N モジュール x 2台を用いたメカナムホイール4輪ロボットの制御ファームウェアです。
M5Stack Joystick2 Unit による有線操作およびスマートフォンからの BLE UART リモートコントロールに対応しています。

---

## 1. ハードウェア構成と配線仕様

### 接続構成
- **コントローラ**: M5StickC Plus SE (ESP32-PICO-D4 + AXP192)
- **Grove I2C ポート**:
  - `GPIO 32` : SDA
  - `GPIO 33` : SCL
  - `5V / GND`
- **I2C スレーブデバイス**:
  - PCA9685 PWM ドライバー (`0x40`, PWM周波数: 1000Hz)
  - M5Stack Joystick2 Unit (`0x52`, バックアップで `0x63` にも自動対応)
- **モータードライバー**: L298N モジュール x 2台 (ENA/ENBはジャンパーで常時有効)

### PCA9685 出力チャンネルアサイン
| チャンネル | 接続先 | 備考 |
|:---:|:---:|:---:|
| Ch 0 | FL (左前) IN1 | 正転時にPWM出力 |
| Ch 1 | FL (左前) IN2 | 逆転時にPWM出力 |
| Ch 2 | FR (右前) IN3 | 正転時にPWM出力 |
| Ch 3 | FR (右前) IN4 | 逆転時にPWM出力 |
| Ch 4 | RL (左後) IN1 | 正転時にPWM出力 |
| Ch 5 | RL (左後) IN2 | 逆転時にPWM出力 |
| Ch 6 | RR (右後) IN3 | 正転時にPWM出力 |
| Ch 7 | RR (右後) IN4 | 逆転時にPWM出力 |

※FA-130モーターの定格電圧およびL298Nの電圧降下を考慮し、PWMデューティ比は最大 **75% (3071 / 4095)** に制限されています。

## 2. 操作方法

### 制御ソースの自動切り替え
1. **BLE接続時**: BLEからの指令が最優先されます。
2. **BLE未接続時**: Joystick2 Unit からの入力を読み取って走行します。
3. **安全非常停止 (E-STOP)**: M5StickC Plus SE の正面「M5ボタン (ボタンA)」を押すと、即座に全モーターが停止し画面に `[E-STOP]` と表示されます。もう一度押すと解除されます。

---

### 【Step 1】Joystick2 による有線操作
- **通常時 (ボタン非押下)**:
  - スティック前後: 前進・後退 ($V_y$)
  - スティック左右: 左右平行移動 ($V_x$)
- **ボタン押下時**:
  - スティック左右: 超信地旋回 / 旋回角速度 ($\Omega$)
  - スティック前後: 前進・後退 ($V_y$) を維持
- **デッドゾーン**: 中心付近の微小入力 ($\pm 0.08$) は不感帯としてカットされ、静止時の微振動を防止します。

---

### 【Step 2】BLE UART によるワイヤレス操作
汎用スマホアプリ（「Serial Bluetooth Terminal」(Android) や「BLE Terminal / BLE Controller」(iOS)）から接続可能です。

- **デバイス名**: `M5-Mecanum-Rover`
- **Nordic UART Service (NUS) UUID**:
  - サービス UUID: `6E400001-B5A3-F393-E0A9-E50E24DCCA9E`
  - RX UUID (送信先): `6E400002-B5A3-F393-E0A9-E50E24DCCA9E`
  - TX UUID (受信元): `6E400003-B5A3-F393-E0A9-E50E24DCCA9E`

#### コマンド形式
1. **カンマ区切りテキスト**:
   `Vx,Vy,Omega` (-1.0 〜 1.0)
   - 例: `0.0,0.8,0.0` (前進 80%)
   - 例: `0.6,0.0,0.0` (右平行移動 60%)
   - 例: `0.0,0.0,0.5` (時計回り旋回 50%)
   - 例: `0.0,0.0,0.0` (停止)
2. **ショートカットキー (ボタンへの割り当て用)**:
   - `F` : 前進 (Vy = 0.7)
   - `B` : 後退 (Vy = -0.7)
   - `L` : 左平行移動 (Vx = -0.7)
   - `R` : 右平行移動 (Vx = 0.7)
   - `CW` または `TR` : 右旋回 (Omega = 0.7)
   - `CCW` または `TL` : 左旋回 (Omega = -0.7)
   - `S` または `STOP` : 停止
3. **バイナリパケット**:
   `[0xAA, 0x55, int8_t(Vx * 100), int8_t(Vy * 100), int8_t(Omega * 100)]`

#### フェールセーフ機能
- BLE切断時、またはパケット受信間隔が **500ms** を超えた場合、即座に全モーターへのPWM出力を0にして完全停止します。
- 画面フッターに `BLE:TIMEOUT` と赤色警告が表示されます。

## 3. ディスプレイUI (ST7789v2 縦向き 135x240: ボタンAが下の向き)
M5Canvas ダブルバッファによるチラツキのない高速リアルタイム描画（約30fps）を搭載:
- **ヘッダー (上部)**: タイトル、バッテリー残量・電圧、制御モード (`[JOYSTICK]`, `[BLE-NUS]`, `[FAILSAFE]`, `[E-STOP]`)
- **入力カード (中上部)**: $V_x, V_y, \Omega$ 数値表示 + 生データ/中心値 + 2Dミニクロスヘアインジケータ
- **モーター出力カード (中下部)**: 4輪（FL, FR, RL, RR）の PWM 出力値 (0〜3071) および回転方向 (`FWD`, `REV`, `--`)
- **ステータスカード (下部)**: I2Cデバイス検出状態 (`PCA:OK`, `JOY:0x52`), BLE通信モニタ (`BLE:OK(XXms)`), ボタン機能ガイド (`A:ESTOP | B:ZERO-CAL`)

## 4. ビルドと書き込み方法
PlatformIO CLI または VS Code の PlatformIO 拡張機能から書き込みます。

```bash
# ビルド
pio run

# ファームウェアの書き込み
pio run --target upload

# シリアルモニターの起動 (115200bps)
pio run --target monitor
```
